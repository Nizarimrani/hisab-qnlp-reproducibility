# Historical IBM Quantum records

`jobs.json` transcribes source cells and embedded outputs from a private historical notebook. The record includes four completed jobs on `ibm_kyiv`, their shot counts, and returned counts.

The original notebook is not published because it contains credentials and exploratory material. Its SHA-256 checksum is retained in the private evidence archive.

The current record is **hardware-traceable**, not a complete hardware archive. IBM-side timestamps, calibration properties, physical layouts, and transpiled circuits remain to be recovered from the owning account where available.
